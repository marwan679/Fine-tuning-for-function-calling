# Gemma-2-2B-it Thinking Function Calling 🚀

This repository contains a Google Colab notebook demonstrating how to fine-tune **Google's Gemma-2-2B-IT** model to perform **function calling** enhanced with an explicit **"thinking"** step.

The project builds upon a custom subset of the `NousResearch/hermes-function-calling-v1` dataset, augmented with reasoning traces generated by `deepseek-ai/DeepSeek-R1-Distill-Qwen-32B` to improve planning and execution accuracy before invoking tools.

---

## Features & Highlights

* **Model Quantization & Parameter-Efficient Fine-Tuning (PEFT):** Uses `bitsandbytes` for memory-efficient loading and `peft` with LoRA adapters targeting linear and embedding layers.


* **Explicit Reasoning Steps (`<think>`):** Trains the model to plan tool usage using `<think></think>` blocks prior to generating tool calls (`<tool_call></tool_call>`), drawing inspiration from test-time compute scaling approaches.


* **Custom Special Token Integration:** Extends the tokenizer vocabulary with dedicated chatml-style tags (`<tools>`, `<think>`, `<tool_call>`, `<tool_response>`) and updates the chat template accordingly.


* **Hub Integration:** Automated scripts to push trained LoRA weights and updated tokenizer configurations directly to the Hugging Face Hub.

## Quick Start / Usage

1. **Open in Google Colab** (or run locally on a GPU-enabled machine with at least one T4 or better).
2. **Set your Hugging Face Token** with write access within the environment variables (`os.environ['HF_TOKEN']`).


3. **Run the cells sequentially** to:
* Install and import dependencies.


* Preprocess and tokenize the dataset (`Jofthomas/hermes-function-calling-thinking-V1`).


* Configure special tokens and resize token embeddings.


* Set up LoRA parameters and `SFTTrainer` hyper-parameters.


* Execute training and push the resulting adapter and tokenizer to your Hugging Face Hub profile.

## Inference Example

Once trained and pushed, load your model and adapter for inference as follows:

```python
from peft import PeftModel, PeftConfig
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

peft_model_id = "your-username/gemma-2-2B-it-thinking-function_calling-V0"
config = PeftConfig.from_pretrained(peft_model_id)

model = AutoModelForCausalLM.from_pretrained(config.base_model_name_or_path, device_map="auto")
tokenizer = AutoTokenizer.from_pretrained(peft_model_id)
model.resize_token_embeddings(len(tokenizer))
model = PeftModel.from_pretrained(model, peft_model_id)
model.eval()

```
